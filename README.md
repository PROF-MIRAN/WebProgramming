# 🤖 Web Programming

2026학년도 웹프로그래밍 강의자료 및 실습자료

대구대학교 컴퓨터소프트웨어전공 **웹 프로그래밍(Web Programming)** 수업 실습 저장소입니다.

HTML, CSS, JavaScript를 단계적으로 학습하고, 이후 React를 활용한 웹 애플리케이션 개발까지 진행합니다.

---

## 수업 목표

이 저장소에서는 매주 수업 시간에 작성한 실습 코드를 주차별로 관리합니다.

주요 학습 내용은 다음과 같습니다.

- HTML5 기본 구조와 핵심 태그
- CSS 기본 문법과 레이아웃
- JavaScript 기본 문법
- DOM 및 이벤트 처리
- 웹페이지 인터랙션 구현
- React 기초
- 웹 프로젝트 제작
- Git / GitHub를 활용한 소스코드 관리

## Git 실습 방법

수업 시간에 작성한 코드는 매주 Git으로 Commit하고 GitHub에 Push합니다.

### 변경 파일 확인

```bash
git status
```

### 파일 추가

```bash
git add .
```

### Commit

```bash
git commit -m "1주차 HTML 기본 실습"
```

### GitHub에 Push

```bash
git push
```

---

## 실습 진행 방식

매주 수업에서 다음 과정을 반복합니다.

```text
수업 실습
   ↓
파일 작성 및 수정
   ↓
Git Add
   ↓
Git Commit
   ↓
Git Push
   ↓
GitHub에서 Commit 이력 확인
```

GitHub의 **Commits** 메뉴에서 본인의 주차별 실습 기록을 확인할 수 있습니다.

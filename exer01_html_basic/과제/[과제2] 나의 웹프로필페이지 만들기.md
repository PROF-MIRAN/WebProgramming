# 실습 과제: 나의 웹 프로필 페이지 만들기

## 1. 과제 목표

이번 과제에서는 HTML 기본 태그를 활용하여 **나의 웹 프로필 페이지**를 제작합니다.

수업 시간에 학습한 HTML 문서 구조와 주요 태그를 사용하여 하나의 완성된 웹페이지를 만들고, Git을 이용해 커밋한 뒤 GitHub에 Push 합니다.

## 3. 필수 구현 내용

### ① 페이지 제목 및 소개

페이지 상단에 다음 내용을 작성합니다.

- 페이지 제목: `나의 웹 프로필`
- 간단한 소개 문장 작성
- 메뉴 링크: `nav`로 구성

예시 메뉴

- 소개
- 관심 분야
- 학습 계획
- 문의하기

---

### ② 자기소개

다음 내용을 포함하여 자기소개 영역을 작성합니다.

- 자기소개 제목
- 인사말
- 현재 공부하고 있는 내용
- 앞으로 배우고 싶은 내용
- 프로필 이미지 1개
---

### ③ 관심 분야

`ul`, `ol`, `li` 태그를 사용하여 관심 분야와 학습 순서를 작성합니다.

예시:

**관심 있는 기술**

- HTML
- CSS
- JavaScript
- React

**학습 순서**

1. HTML 배우기
2. CSS 배우기
3. JavaScript 배우기
4. 웹 프로젝트 만들기

---

### ④ 학습 계획

`table` 태그를 사용하여 자신의 학습 계획을 작성합니다.

예시:

| 주차 | 학습 내용 | 상태 |
|---|---|---|
| 1주차 | HTML 기본 | 학습 완료 |
| 2주차 | CSS 기본 | 학습 예정 |
| 3주차 | JavaScript 기본 | 학습 예정 |

최소 **3개 이상의 학습 계획**을 작성하세요.

---

### ⑤ 문의하기

`form` 태그를 활용하여 다음 입력 항목을 작성합니다.

- 이름
- 비밀번호
- 이메일
- 생년월일
- 학년
- 관심 분야
- 배우고 싶은 기술
- 웹 프로그래밍 수준
- 문의 내용
- 제출 버튼
- 초기화 버튼

---

### ⑥ 참고 사이트

HTML 학습에 도움이 되는 참고 사이트 링크를 1개 이상 추가하세요.

예시:

```html
    HTML에 대해 더 공부하고 싶다면?
```

---

### ⑦ Footer

페이지 하단에 Footer를 작성합니다.

## 4. 파일 구성

실습 폴더는 다음과 같이 구성합니다.

```text
exer01_html_basic/
│
├── 05_total_practice.html
└── profile.png
```

- HTML 파일명: `05_total_practice.html`
- 프로필 이미지 파일명: `profile.png`

프로필 이미지는 본인의 사진이 아니어도 됩니다.

## 8. 주의사항

- CSS를 사용하지 않아도 됩니다.
- 이번 과제의 핵심은 **HTML 태그의 구조와 사용법**입니다.
- 수업 시간에 학습한 태그를 최대한 활용하세요.
- 예제 화면과 완전히 동일하게 만들 필요는 없으며, 내용은 자유롭게 변경할 수 있습니다.
- 단, 위의 **필수 구현 요소는 모두 포함**해야 합니다.
